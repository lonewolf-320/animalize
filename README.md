# Animalize — Animalize Your Living

A modern pet adoption and community platform built with React, Tailwind CSS, and Babel (CDN-based, no build step required).

## Quick Start

Simply open `index.html` in your browser, or serve the directory with any static file server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```

## Tech Stack

- **React 18** (via CDN)
- **Tailwind CSS** (via CDN)
- **Babel Standalone** (in-browser JSX transpilation)
- **DM Sans** (Google Fonts)

## Project Structure

```
├── index.html          # Entry point
├── app.jsx             # Main App component & routing
├── components.jsx      # Shared UI components
├── home-page.jsx       # Home page
├── events-page.jsx     # Events page
├── info-pages.jsx      # Info/about pages
├── pet-data.jsx        # Pet data definitions
├── tweaks-panel.jsx    # Theme/settings panel
└── uploads/            # Uploaded assets
```
